# Program icon

`gen_app_icon.sh` writes the program icon outside the window (architect 2026-10-12): `assets/icons/adwaita-3.22/AppIcon.svg`, Adwaita 3.22's document-open-recent clock with its back arrow turned forward since 2026-10-17 late evening (the caption's icon, byte-identical to `DocumentOpenRecentForward.svg`, the glyph Warp wears; the BPM Iterations button keeps Adwaita 3.22's audio-x-generic note, the program icon from 2026-10-12 until then) over white, flat (architect 2026-10-17): #FFFFFF, one color over the whole square — Windows Storm's caption start #800080 was the ground from 2026-10-16 until then, the Cool Edit case's 20 face-ramp bands under Midnight's Face from 2026-10-12 before it. The ground is the Android icon's alone. Outputs: `packaging/warptempo_gui.svg`, the Linux desktop icon (the `.desktop`'s `Icon=`), a 48 x 48 document with the BARE drawing on transparency, no ground (the freedesktop convention; Android's adaptive mask demands a full-bleed square, Linux desktops take any shape: two framings is normal), verbatim as a nested `<svg>` (its bytes whole: the set's files carry no XML declaration); and the Android adaptive icon's two PNG layers per density under `android/app/res/mipmap-<density>/`, the foreground rasterised antialiased by `rsvg-convert` at 52 dp (architect 2026-10-16, his pick off a 60 / 56 / 52 / 48 / 44 / 40 dp series) on the transparent 108 dp canvas, the background that canvas flat in #FFFFFF (`android/app/res/mipmap-anydpi-v26/ic_launcher.xml`'s head holds the table). `bash tools/app_icon/gen_app_icon.sh`; byte-stable; regenerate, never hand-edit. Needs `rsvg-convert` (librsvg) and ImageMagick 7; a standalone utility with no link path from any product target.
