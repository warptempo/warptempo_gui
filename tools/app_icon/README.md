# Program icon

`gen_app_icon.sh` writes the program icon outside the window (architect 2026-10-12): `assets/icons/adwaita-3.22/AppIcon.svg`, the architect's digital metronome since 2026-10-16 (the icon set's one own file: the caption's icon, byte-identical to `DigitalMetronome.svg`, the glyph Warp wears; the BPM Iterations button keeps Adwaita 3.22's audio-x-generic note, the program icon from 2026-10-12 until then) over the chrome's own caption start, flat (architect 2026-10-16: "just the title start color, flat, as the bg"): the compiled scheme's active title start, Windows Storm's #800080 (`src/gui/chrome_schemes.inc`'s `windows-storm` row; `kGuiCaptionOwn` names the scheme), one color over the whole square — the Cool Edit case's 20 face-ramp bands under Midnight's Face were the ground from 2026-10-12 until then. The ground is the Android icon's alone. Outputs: `packaging/warptempo_gui.svg`, the Linux desktop icon (the `.desktop`'s `Icon=`), a 48 x 48 document with the BARE drawing on transparency, no ground (the freedesktop convention; Android's adaptive mask demands a full-bleed square, Linux desktops take any shape: two framings is normal), verbatim as a nested `<svg>` (its bytes whole: the set's files carry no XML declaration); and the Android adaptive icon's two PNG layers per density under `android/app/res/mipmap-<density>/`, the foreground rasterised antialiased by `rsvg-convert` at 52 dp (architect 2026-10-16, his pick off a 60 / 56 / 52 / 48 / 44 / 40 dp series) on the transparent 108 dp canvas, the background that canvas flat in #800080 (`android/app/res/mipmap-anydpi-v26/ic_launcher.xml`'s head holds the table). `bash tools/app_icon/gen_app_icon.sh`; byte-stable; regenerate, never hand-edit. Needs `rsvg-convert` (librsvg) and ImageMagick 7; a standalone utility with no link path from any product target.

The drawing is NOT adwaita-icon-theme's: the architect's own (2026-10-16), made with Google's Gemini after a Korg MA-1 in Adwaita 3.22's manner and cleaned on tablet mocks, licensed under the GNU LGPL v3, the set's licence (architect 2026-10-15), and shipped as a separate data file beside the GPL-3 program; its lettering is the outlines of DejaVu Sans Bold, under the Bitstream Vera licence (`fonts/LICENSE-DejaVu.txt`). Its provenance and the licence texts are `assets/icons/adwaita-3.22/README.md`'s, the tracked source `tools/icon_set_adwaita_322/own/DigitalMetronome.svg`. The ground is Windows 95 Plus!'s Storm scheme's caption color, a single value from the product's compiled scheme catalog.
