# Program icon

`gen_app_icon.sh` writes the program icon outside the window from `assets/icons/warptempo/AppIcon.svg`, the caption's own speaker (architect 2026-10-06): `packaging/warptempo_gui.svg`, the Linux desktop icon (the `.desktop`'s `Icon=`), AppIcon's paths verbatim in a standalone 16 x 16 viewBox; and the Android adaptive icon's two PNG layers per density under `android/app/res/mipmap-<density>/`, the foreground rasterised antialiased by `rsvg-convert` at 64 dp on the transparent 108 dp canvas (`android/app/res/mipmap-anydpi-v26/ic_launcher.xml`'s head holds the table). `bash tools/app_icon/gen_app_icon.sh`; byte-stable; regenerate, never hand-edit. Needs `rsvg-convert` (librsvg) and ImageMagick 7; a standalone utility with no link path from any product target.
