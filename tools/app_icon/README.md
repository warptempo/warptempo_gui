# Program icon

`gen_app_icon.sh` writes the program icon outside the window (architect 2026-10-12): GNOME 2.28's `MusicNote16th.svg` (`assets/icons/gnome-2.28/`, the drawing the BPM Iterations button wears) over the button case's gradient, the Cool Edit case's 20 face-ramp stops under the default palette's Face (Midnight, #272B6D) by `src/gui/cool_edit_derive.h`'s `kCaseRamp`, as flat bands over the whole square the way `paint_face_ramp` spreads them over the glyph seat (no interpolation; the case's highlight, shadow and black line are not drawn). The bands are the Android icon's alone. Outputs: `packaging/warptempo_gui.svg`, the Linux desktop icon (the `.desktop`'s `Icon=`), a 48 x 48 document with the BARE drawing on transparency, no ground (the freedesktop convention; Android's adaptive mask demands a full-bleed square, Linux desktops take any shape: two framings is normal), verbatim as a nested `<svg>` (its bytes less the XML declaration); and the Android adaptive icon's two PNG layers per density under `android/app/res/mipmap-<density>/`, the foreground rasterised antialiased by `rsvg-convert` at 64 dp on the transparent 108 dp canvas, the background that canvas in the same 20 bands (`android/app/res/mipmap-anydpi-v26/ic_launcher.xml`'s head holds the table). `bash tools/app_icon/gen_app_icon.sh`; byte-stable; regenerate, never hand-edit. Needs `rsvg-convert` (librsvg) and ImageMagick 7; a standalone utility with no link path from any product target.

## Provenance and licence

The drawing is gnome-icon-theme 2.28.0's, GPL-2 only, shipped as a separate data file beside the GPL-3 program; its provenance, licence texts and the reasoning are `assets/icons/gnome-2.28/README.md`'s. The 20 tones in the generator are this program's own derivation, not a third party's.
