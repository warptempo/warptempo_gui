# Program icon

`gen_app_icon.sh` writes the program icon outside the window from `assets/icons/mist/AppIcon.svg`, GNOME's audio-x-generic from the Mist set (architect 2026-10-06, the drawing the caption wore; the Mist set's since 2026-10-07, kept 2026-10-09), on the ground #EDECEB: `packaging/warptempo_gui.svg`, the Linux desktop icon (the `.desktop`'s `Icon=`), a 48 x 48 document with a ground-colored rect behind AppIcon.svg verbatim as a nested `<svg>` (its bytes less the XML declaration); and the Android adaptive icon's two PNG layers per density under `android/app/res/mipmap-<density>/`, the foreground rasterised antialiased by `rsvg-convert` at 64 dp on the transparent 108 dp canvas, the background that canvas in the solid ground (`android/app/res/mipmap-anydpi-v26/ic_launcher.xml`'s head holds the table). `bash tools/app_icon/gen_app_icon.sh`; byte-stable; regenerate, never hand-edit. Needs `rsvg-convert` (librsvg) and ImageMagick 7; a standalone utility with no link path from any product target.
