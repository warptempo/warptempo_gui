# THE PROGRAM'S COLOR PRESETS — THE ONE SOURCE OF THE BUILT-IN PALETTES (gen_presets.py writes
# src/gui/palette_presets.inc from this file). PROVENANCE: ONE INK, the DEC VT220's green 49CA8A (HLS hue 150,
# saturation .55, lightness .54), under ONE CUE COLOR per preset. THE CUE SITS ON THE CANVAS BLACK ALONE since the
# knockout (architect 2026-10-26: a marker's dot that lands on the waveform is painted in the canvas color,
# src/gui/canvas_sink.h's head), so its lightness is free — his words: "It opens a lot more possibilities for colors,
# including just using the ink itself, or pretty much any other color; we just worry about picking a color that looks
# good with the ink". The anchor, Terminal, Blue (the architect's pick of 2026-10-25 late: Tron's light-cycle blue
# 1CC8FF, the LED-digit red F2142E, Tempest's yellow FFF300), is kept byte for byte as the first row and the default
# (palette_file.h's kGuiDefaultPaletteKey); the other thirty-two are the planner's, each cue with the red it was
# paired with in the earlier rounds. Thirty-three presets; two families among them are terminal palettes mapped:
#  - THE VGA PALETTE MAPPED: the Terminal green (hue 150, sat .55, light .54) is VGA's bright green 55FF55 (hue 120,
#    sat 1.0, light .67) at saturation x .55 and lightness x .81, the hue kept; applied to VGA's bright eight that gives
#    cyan 49CACA, blue 4949CA, magenta CA49CA, yellow CACA49 and light red CA4949 (the family's invalid). Three ROTATED
#    rows add the 30-degree hue turn the green itself carries (VGA green 120 -> 150): azure 498ACA, rose CA498A,
#    violet 8A49CA.
#  - THE TANGO PALETTE (XFCE's and GNOME's terminal default) MAPPED: Tango's chameleon 8AE234 is the Terminal green at
#    saturation x .69, the lightness kept; so sky blue 729FCF -> 80A1C2, plum AD7FA8 -> A687A3, orange FCAF3E ->
#    DFAB5D, scarlet EF2929 -> D04949 (the family's invalid).
# EVERYTHING ELSE ONE VALUE ON EVERY ROW: the ink WvFg 49CA8A (Terminal) and its grid GrdL 0F2E1F (the ink's hue at
# HLS saturation .5 and lightness .12); the playhead Curs FFF300 (Tempest's yellow); the center line Cntr A53038; WvBk
# 000000; Face 626C7B (the record; no surface reads it). The outline is derived and the scanner fixed white by the
# generator's rules (its head).
