# with no name line in the exe's text named from Cool Edit's own registry entries written under Wine on his laptop the

# But maybe the range should return, and we could test the Cool Edit themes but only on the markers — the default Cool
# Edit markers contrast well, with the flag in red and the range in blue." — "Do both at once — the point is to get

# ink."

# F34B58 -> CA4959, RngM 4B82F3 -> 4979CA, GrdL 003500 -> 0A2509, Curs FFFF00 -> B3AD29, Face 626C7B -> 595F66.
