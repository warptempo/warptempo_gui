Requires `separators: "none"` (refuse in one line otherwise) and is mutually exclusive with `sep_gap` (refuse in one line if both set). It re-packs like the others (gap null + group_space set packs with each pair's own measured step). In the pack an inner separator's span (gl + s.w + gr) becomes group_space·S: give the separator w 0 and park its x at the span's middle (nothing paints it; the overlap check must still pass). A break separator (the icon row's view separator) keeps its measured kept gap as today (the view group stays flush right). Validation like the siblings (whole number, not bool, >= 0).
