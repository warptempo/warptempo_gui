## The doctrine

Four failure classes, each with ONE owner:

1. **ADVERSARIAL input** (hand-edited/corrupt files, absurd values) → the **LOAD boundary**. First-error hardfail, loud, identical in both binaries ("loadable in both products or neither"). The product contract.
2. **AMBIGUOUS authored state** → the **RESOLVER** (and its phase-reset sibling). Normalizes, never refuses; one stderr line per timestamp per resolve is the signal (directive #11).
3. **LEGAL-BUT-UNHONORABLE state** → the owning stage refuses **CONSTRUCTIVELY** (plan_trim: refusal = render untrimmed, never a failed render).
4. **PROGRAM BUGS (breach)** → the **ENGINE INIT tripwires**: the last point before silently-wrong bytes, validating the actual consumed artifact in both binaries. Breach loudness elsewhere (abort / terminate / stderr+Failed) is justified only where the engine cannot see the breach.
5. **ADVISORY signals**: stderr-and-continue, owning no failure — the fftw-threads single-thread fallback, the framemap-pair write failure (inert future-proofing). Never fatal. (The class had a third member, the render-env hash mismatch, until 2026-08-09: the four attestation settings keys, the GUI's load-time advisory prompt and the CLI's equivalent stderr line were deleted whole with the ruling that library drift is bounded at inaudible classes post-`-ffp-contract=off`. A class loses a member without losing its rule.)

A predicate may exist at TWO boundaries only when:

- **(a)** the downstream owner cannot catch it — or cannot catch it CLEANLY (sub-frame gap — the engine checks ascent, not spacing; dangling label ref — the engine never consumes refs; apply_post_trim's crop contract — only it holds both buffer and window; the worker's inode-level clobber check — batch paths and write-time races only it can see; map-target FINITENESS — the builder's emission contract, because the orchestrators llrint the final anchor before the engine validates, and llrint on a non-finite value is an invalid conversion with an unspecified result: only the producer refuses it cleanly);
- **(b)** the upstream site has message vocabulary the downstream lacks (the sweep tempo<=0 backstop names the tempo; the engine could only say "not strictly ascending");
- **(c)** an explicit architect symmetry ruling covers it (the past-EOF column pair; the GUI/CLI shared-implementation load checks).

**Type rule**: an error arm (std::expected / optional / bool-false) exists iff a producer exists — reachable, breach-only, or IO, and the classification names which. Total normalizers return plain values (resolve_warp_markers_for_render); partial compilers keep expected (build_warp_frame_map).

**Out-of-topology labels** (things a guard-shaped grep hits that are not guards): LIVE FUNCTIONALITY (cancel checks, capability-loss release tails, the limiter's pass cap), DOMAIN INVARIANT (the clamp chokepoints — constructive, never refuse), DISPLAY-ONLY (`marker_effective` / `compute_hover_popup_text` safe-returns — no bytes, no stderr; only the HOVER half of the second name is history, the row-5 redesign having deleted the hover popup and the whole occlusion resolver with it — the function survives repurposed as the SELECTION READOUT, painted from paint_handler.cpp and its payload copied by Ctrl+C at input_handler.cpp, so the classification is unchanged), INTERACTIVE VOCABULARY (editor red-flash — the same validators the load runs, UI surfacing only: "loadable iff it commits"), ENVIRONMENT PRECONDITION (the CLI's locale/arg checks — guard the launch, not the data), INPUT ROUTING (added 2026-07-28 — the KEYBOARD gates: `read_only_key_blocked`'s allowlist, `modal_editor_key_blocked`, and `text_editor::classify_key`. They decide whether a key reaches a command AT ALL; they never judge data. No error arm, no stderr, no refusal vocabulary, no producer — a gated key is a consumed no-op, and the routing question "does this press run" is upstream of every question this doctrine asks. IT IS A KEYBOARD LABEL AND IT STAYS ONE (architect 2026-08-03): the 2026-08-02 widening had handed it two POINTER members, and keyboard rules should not cover the pointer — both moved to the sibling GESTURE ROUTING, which was itself deleted on 2026-08-07 when those two guards were. What the widening added and this label kept was the SETTINGS EDITOR's TRIM ARM read-only refusal — a TYPED route, where Enter commits a `trim=` value, so the pointer/keyboard split did not reach it — and THAT REFUSAL IS DELETED (architect 2026-08-07, trim reclassified as band): the label's membership is back to the three keyboard gates alone. GESTURE ROUTING, the pointer sibling added 2026-08-03, IS DELETED (architect 2026-08-07): its whole roster was the plain trim-bar press's band gate and the bound-set click's refusal in `trim_bound_click_frame`, both deleted with the reclassification of trim as band, and an out-of-topology label with no members is dead code. THE STANDARD SINCE 2026-08-07 (architect, superseding the 2026-07-28 "persistent mutation" one whole): **READ-ONLY PROTECTS THE AUTHORED MUSICAL CONTENT — the two marker stores and the engine settings — AND NOTHING ELSE.** The per-tab BAND (viewport, zoom, playhead, TRIM and the `read_only` bit itself) is read-only-LEGAL, and so are SAVE and RENDER: a save writes the state the tab already holds and a render reads it, so neither authors anything. THE OLD STANDARD'S CONFORMING INSTANCE, bare `t`'s session-only iter wipe, is doubly retired: the wipe left `t` on 2026-08-07 with the target-legal iteration ruling, and the standard it conformed to is gone. THE ITERATION SWEEP's own tail carries that same session-only write — reachable in a locked tab, the iteration bit being global rather than per-tab — and the architect RATIFIED it that day on three reasons, recorded at the gate: iteration brackets are never saved; the wipe mutates no marker permanently, clearing session-only fields and leaving every authored position, tempo and label untouched; and the sweep leaves its own trace in the `tmp/` folder, making the act self-documenting output rather than silent authoring.
